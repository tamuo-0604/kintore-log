# 筋トレログ

メニューを選んで回数を記録するだけの、シンプルな筋トレ記録アプリです。
iPhone と iPad の両方で使えます。データは端末の中だけに保存され、外部には送信しません。

このリポジトリには、中身（データの形・機能）が同じ 2 つの版が入っています。

| フォルダ | 何か | 状態 |
|---|---|---|
| `web/` | **PWA 版**（Safari で開いて「ホーム画面に追加」するとアプリのように使える） | 動作確認済み。まずはこちらで試す |
| `ios/` | **ネイティブ版**（SwiftUI。Mac の Xcode でビルドして入れる） | 準備中。主要機能は実装済みだが未ビルド |

## できること

- **記録**: メニューをタップ → 重量と回数を ＋／− で調整 → 「記録」。前回の値が最初から入っています
- **前回の記録と自己ベストを表示**: 入力中に「前回は何 kg × 何回だったか」が常に見える
- **自己ベスト更新のお知らせ**: 推定 1RM（重量種目）や最高回数を更新すると通知
- **休憩タイマー**: 記録すると自動でセット間のカウントダウン開始（＋30 秒・スキップ可）
- **履歴**: カレンダーでトレーニングした日がひと目でわかる。セットの修正・削除、過去の日への追記
- **分析**: 今週の日数／ボリューム、継続週数、週ごとの推移、部位バランス、種目別の伸びグラフ
- **メニュー管理**: 追加・編集・一時的に隠す。記録のしかたは 5 タイプ（重量×回数／回数のみ／秒数／HIIT／距離×時間）
- **HIIT タイマー**: 本数・高強度の秒数・インターバルの秒数・開始前の準備秒数をメニューに定義し、全画面タイマーで実施。終わると自動で記録
- **有酸素**: ランニングなどを距離と時間で記録。ペース（1km あたり）も表示
- **からだの記録**: 体重を 1 日 1 件記録し、推移をグラフで確認。体脂肪率・筋肉量・ウエストも任意で記録できる
  - 目標体重を決めると、グラフに目標の線と「あと何 kg」を表示
  - 体重グラフには 7 日平均の線が入り、日々の増減に惑わされず傾向が分かる
  - 身長を入れると BMI と標準体重、体脂肪率から除脂肪体重も表示
- **端末間の同期**: iPhone と iPad で同じ記録を使える（自分の GitHub アカウントに保管。PWA 版のみ）
- **バックアップ**: JSON の書き出し・復元、CSV 書き出し（Excel 用）
- ダーク／ライト自動切り替え、オフライン動作、iPad では 2 カラム表示

## PWA 版を使う

### iPhone / iPad に入れる（GitHub Pages）

1. GitHub のリポジトリ画面で **Settings → Pages → Source** を **GitHub Actions** にする
   （非公開リポジトリで Pages を使うには GitHub の有料プランが必要です。無料プランの場合はリポジトリを公開にします）
2. `main` ブランチに push すると `.github/workflows/pages.yml` が自動で公開します
3. iPhone / iPad の **Safari** で公開 URL を開き、共有ボタン →「ホーム画面に追加」

### パソコンで試す

```bash
cd web
```

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

### ファイル構成

- `index.html` … 土台
- `styles.css` … 見た目（色は先頭の変数で変更できます）
- `app.js` … 動き（データ保存、各画面）
- `sw.js` … オフライン対応
- `manifest.webmanifest`, `icons/` … ホーム画面に追加したときの名前とアイコン

ビルド作業は不要で、ファイルを置くだけで動きます。

## ネイティブ版（準備中）

Mac と Xcode が必要です。

```bash
brew install xcodegen
```

```bash
cd ios && xcodegen && open KintoreLog.xcodeproj
```

Xcode で自分の Apple ID（Signing & Capabilities → Team）を選び、実機を接続して ▶ を押します。
`ios/project.yml` の `PRODUCT_BUNDLE_IDENTIFIER` は自分だけの文字列に変えてください。

push すると `.github/workflows/ios-build.yml` が GitHub 上の Mac でビルドできるかを自動チェックします。

HIIT タイマーはネイティブ版にもあります。PWA 版と違い、消音モードでも音が鳴り、切り替わりで振動し、タイマー中は画面が消えません。

### ヘルスケア連携（ネイティブ版のみ）

メニュータブの「ヘルスケアと連携」をオンにすると、許可の画面が出ます。読み書きしたい項目をオンにして「許可」を押してください。

- **読み込み**: 体重・体脂肪率・ウエスト・身長。体組成計のアプリなどがヘルスケアに書き込んだ値を、からだの記録に取り込みます。アプリを開いたときに自動で行います
  - その日の記録がまだないときだけ新しく作り、アプリで入力した値は上書きしません。空いている項目（体脂肪率・ウエスト）は埋めます
  - アプリで削除した日は取り込み直しません
- **書き出し**: アプリで記録した体重・体脂肪率・ウエスト・身長。修正すると上書きされ、削除するとヘルスケアからも消えます
- **ワークアウト**: HIIT（「高強度インターバルトレーニング」）と有酸素を保存します。有酸素の種類はメニュー名から判断します（「ラン」→ランニング、「ウォーキング」→ウォーキング、「バイク」→サイクリングなど）
- 筋肉量はヘルスケアに対応する項目がないため連携しません。筋トレのセットもワークアウトとしては保存しません
- iPad で使えるのは iPadOS 17 以降です

PWA 版との違い（今後そろえる部分）: 履歴はカレンダーではなく日付の一覧。部位バランスのグラフ、CSV 書き出し、端末間の同期は未実装。

## HIIT タイマーの使い方

1. 記録タブで HIIT のメニュー（例: タバタ式）を選ぶ
2. 本数・高強度の秒数・インターバルの秒数・開始前の準備秒数を確認（その場で変更もできます）
3. 「タイマーをスタート」→ 準備（0 秒にするとすぐ 1 本目）→ 高強度と休憩を本数ぶん繰り返し
4. 終わったら「記録して閉じる」。途中で終了した場合は、やり終えた本数だけ記録できます

残り 3 秒からはカウント音が鳴り、数字が弾んで輪が広がります。
PWA 版は「HIIT 中は消音モードでも鳴らす」（設定、初期値オン）で消音モード中も鳴らせますが、その間ほかのアプリの音楽が止まることがあります。音楽を聴きながら使う場合はオフにしてください（ネイティブ版は音楽を止めずに鳴ります）。
タイマー中は画面が消えないようにしていますが、別のアプリに切り替えている間は音が鳴りません（戻ると正しい位置から再開します）。

## 端末間の同期（PWA 版）

記録データを自分の GitHub アカウントの「非公開 Gist」に 1 ファイルで保管し、各端末がそれを読み書きします。

### 設定（最初の 1 回）

1. アプリの「メニュー」タブ → 「端末間の同期」にある **GitHub のトークン作成ページ** を開く
2. Expiration（有効期限）を選ぶ。期限が切れると同期が止まるので、長め（No expiration か 1 年）がおすすめ
3. チェックは **gist だけ**。いちばん下の「Generate token」を押し、表示された文字列（`ghp_…`）をコピー
4. アプリに貼り付けて「同期を始める」
5. もう一台でも同じ文字列を貼り付ける（文字列は作成直後しか表示されないので、2 台目に貼るまでメモしておく）

### 動き方

- アプリを開いたとき・アプリに戻ったとき・記録や編集をした数秒後に自動で同期します
- 同期は記録 1 件ごとに混ぜ合わせるので、2 台で別々に記録してもどちらも残ります。削除や修正も伝わります
- 電波がない場所では端末内に記録され、つながったときに同期されます
- 「すべてのデータを削除」「バックアップから復元」は、ほかの端末にも丸ごと反映されます

### 知っておくこと

- トークンは各端末の中にだけ保存され、Gist やバックアップには含まれません
- 非公開 Gist は一覧には出ませんが、URL を知っている人は中身を見られます（URL は推測できない長い文字列です）
- gist だけにチェックしたトークンでできるのは Gist の読み書きだけで、リポジトリには触れません
- 同期をやめたいときは、アプリの「この端末の同期をやめる」。トークン自体は https://github.com/settings/tokens で削除できます
- ネイティブ版はまだ自動同期に対応していません（データの形はそろえてあります）

## データの引っ越し

PWA 版の「メニュー → バックアップを書き出す」で作った JSON は、もう一台の PWA にも、ネイティブ版にもそのまま読み込めます。
